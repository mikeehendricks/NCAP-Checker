Why some portals get blocked

Every NCAP portal is protected by a bot check (Cloudflare Turnstile on the Quezon City / Parañaque / San Juan platform, reCAPTCHA on Manila, and a WAF on MMDA). This app never bypasses those protections: it drives a real Chromium browser through Playwright, exactly like a person would, and it backs off automatically instead of hammering the sites.

  • Keep the check interval at a few hours or more – set in Admin → Settings → Scheduling.
  • Run the server from a residential or office IP where possible.
  • Use Admin → Sources → Probe to see exactly what a portal returned, including a screenshot.

Where is my MV file number?

On your LTO Certificate of Registration (CR), near your plate number. It is a long digit string such as 1234-1234567890.

Spaces and dashes are ignored – enter it exactly as printed on the CR and the app normalises it.

Automating from a script

Use your API key from the profile page:

curl -X POST \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"plate_number":"ABC1234","mv_number":"1234567890"}' \
  http://your-server/api/lookup
